Repo with the materials for the GIS and Mapping in R Workshops at Cascadia R Conf 2026

Install the following R packages for the Intro (AM) session:
here, dplyr, lubridate, ggplot2, ggthemes, httr, patchwork, viridis, knitr, terra, sf, tidyterra

Install the additional packages for the Intermediate (PM) session:
leaflet, leafem, htmltools, units

Clone this repo and keep all files together as is.
